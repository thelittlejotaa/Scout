# FTC Scouting - Servidor Local

Este sistema é um software leve para scouting presencial na FIRST Tech Challenge.

## Como Executar no VS Code (Recomendado):
1. Crie uma pasta no seu computador chamada `ftc-scout-app`.
2. Dentro dela, crie a pasta `css` e a pasta `js`.
3. Cole os arquivos conforme a estrutura.
4. Abra a pasta no **VS Code**.
5. Instale a extensão **Live Server** (de Ritwick Dey).
6. Clique com o botão direito no `index.html` e escolha **"Open with Live Server"**.

## Como Executar via Terminal (Python):
Caso tenha Python instalado:
```bash
python -m http.server 8000
